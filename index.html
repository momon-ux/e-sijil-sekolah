PENGHANTARAN TERUS KE INBOX GURU

📧 Tetapan Hantar E-mel Automatik (Google Apps Script)

Kenapa guru belum terima sijil dalam Inbox e-mel sebelum ini?

Laman web GitHub Pages tidak mempunyai pelayan e-mel (SMTP) sendiri secara lalai. Untuk membolehkan sistem menghantar fail gambar sijil terus ke dalam Inbox Gmail / DELIMa (@moe-dl.edu.my) secara automatik, anda hanya perlu menampal kod pendek di bawah ke dalam akaun Google anda sekali sahaja (100% Percuma).

Langkah Mudah (Hanya Buat Sekali Sahaja — 2 Minit):

  1. Buka script.google.com dan klik "New Project" (Projek Baharu).
  2. Padam kod asal, kemudian Salin & Tampal (Copy & Paste) kod di bawah:
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var base64 = data.imageBase64.split(',')[1];
  var blob = Utilities.newBlob(Utilities.base64Decode(base64), 'image/png', data.fileName || 'Sijil-SK-Ranggu.png');
  MailApp.sendEmail({
    to: data.email,
    subject: 'e-Sijil Rasmi SK Ranggu: ' + data.title + ' (' + data.serialNo + ')',
    htmlBody: '<p>Tahniah <b>' + data.name + '</b>,</p>' +
              '<p>Bersama e-mel ini dilampirkan e-Sijil rasmi anda bagi <b>' + data.title + '</b>.</p>' +
              '<p><b>No. Siri Sijil:</b> ' + data.serialNo + '<br><b>Sekolah:</b> SK Ranggu, Peti Surat 842, 91008 Tawau</p>',
    attachments: [blob]
  });
  return ContentService.createTextOutput(JSON.stringify({ok: true})).setMimeType(ContentService.MimeType.JSON);
}
